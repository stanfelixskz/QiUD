# QiUD 0.4.0

*(This file is the text for the GitHub release. Paste it into the release description, and attach `QiUD-0.4.0-Setup.exe` and `QiUD-0.4.0-Setup.exe.sha256`.)*

The first public release of **QiUD**: a free data-analysis workbench for Windows. Open a CSV, Excel or JSON file, clean it with a preview before every change, explore it, chart it, and turn the result into an interactive report, all on your own computer.

## Download

**`QiUD-0.4.0-Setup.exe`** (about 75 MB). Windows 10 or 11, 64-bit. Nothing else to install.

SHA-256: `2c77f572945427f0789cf6ffe983fdc57d443f55920efda5240b5e6c2d9b039b`

Windows may say "Windows protected your PC" because the program is not code-signed yet. Choose **More info → Run anyway**. [How to check the download](https://github.com/stanfelixskz/QiUD/blob/main/docs/verify-download.md) · [Install guide](https://github.com/stanfelixskz/QiUD/blob/main/docs/install.md)

## What is in it

- **Open** CSV, Excel (with a sheet picker that finds the header row) and JSON files.
- **Clean with previews:** fill missing values, remove duplicates and matching rows, retype, rename and move columns, add new columns, undo and redo. Your original file is never changed.
- **Explore:** a summary, data-quality checks, group-by, correlation and outliers.
- **Chart:** bar (stacked or side by side), line, summary line, area, scatter, histogram, box plot, pie, donut, Pareto, error bars and heatmaps.
- **Projects and recipes:** keep your work together and replay cleaning steps on the next file.
- **Reports:** a report page with a **live preview**, your own text, titles, colours and chart styles, exported as **one self-contained interactive HTML file** you can email.

## Good to know

- **Free to use, not open source.** The [licence](https://github.com/stanfelixskz/QiUD/blob/main/LICENSE.txt) is shown by the installer.
- **Private by design.** QiUD contains no code that connects to the internet. See [Privacy](https://github.com/stanfelixskz/QiUD/blob/main/docs/privacy.md).
- The live report preview uses Microsoft Edge WebView2 (already on Windows 11 and most up-to-date Windows 10). Without it, everything else still works.

Found a problem? [Open an issue](https://github.com/stanfelixskz/QiUD/issues/new/choose), without private data in it.
