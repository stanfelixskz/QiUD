# Example report

A report made in QiUD from the [sample data](../sample-data) after the cleaning in [tutorial 2](../docs/tutorials/02-clean-your-data.md).

| File | What it is |
|---|---|
| [`coffee-shop-report.html`](coffee-shop-report.html) | The report as QiUD exports it: **one self-contained page** with interactive charts. **Download it and open it in your browser.** (GitHub shows the file's source rather than the page, so use *Download raw file*.) It works offline. Hover over a chart for its numbers and click a legend entry to hide a series. |
| [`coffee-shop-report.pdf`](coffee-shop-report.pdf) | The same page printed to PDF from a browser. |

It shows: a cover and contents, an introduction written by the analyst, a datasets table, eight charts (stacked bars, a summary line, a heatmap, a donut, a Pareto chart, averages with error bars, a histogram and a box plot) each with its own title and, where useful, a caption, collapsible "How this was made" sections listing the cleaning steps, and the work log.

How it was made is in [tutorial 6](../docs/tutorials/06-build-a-report.md).
